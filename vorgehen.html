Der Weg zur Live-Website

Sechs Schritte, in dieser Reihenfolge durchgeführt – von den ersten Inhalten bis zur öffentlich erreichbaren Seite.

01

Inhalte gesammelt

Ausgangspunkt war eine bestehende, einfache Visitenkarten-Seite. Daraus wurden Name, Tätigkeit, Kontaktdaten und die vertretenen Möbelmarken übernommen.

  • Ralf Traphöner — Handelsagentur für Möbel
  • Vertretungen: Nova mobili, Cinquanta 3, Dietsch, La vida
  • Kontakt: E-Mail und Telefonnummer
02

Website gestaltet

Aus den Inhalten entstand eine neue, eigenständige Website als eine einzelne Datei namens index.html — mit Startseite, Vorstellung, Markenübersicht und Kontaktbereich.

Fotos sind derzeit noch Platzhalter und können jederzeit ergänzt werden.

03

Werkzeuge eingerichtet

Zwei kleine Programme wurden auf dem Rechner vorbereitet, um die Datei später veröffentlichen zu können.

  • Git — verfolgt Änderungen an Dateien nach
  • GitHub CLI — verbindet den Rechner mit dem Online-Dienst GitHub
04

Bei GitHub angemeldet

GitHub ist ein kostenloser Online-Dienst zum Speichern und Veröffentlichen von Dateien. Die Anmeldung lief über einen einmaligen Code, den GitHub im Browser bestätigen ließ — ohne dass Zugangsdaten irgendwo eingetippt werden mussten.

05

Projekt hochgeladen

Ein Repository — ein Online-Ordner für die Projektdateien — wurde unter dem Namen ralf-traphoener angelegt. Die Website-Datei wurde dorthin übertragen.

06

Seite veröffentlicht

Über die Funktion GitHub Pages wurde festgelegt, dass der Inhalt des Repositorys als echte Website im Internet erscheint. Wenige Minuten später war sie erreichbar.

Wie man die Seite später aktualisiert

Jede künftige Änderung — neue Fotos, andere Texte, weitere Marken — folgt demselben, immer gleichen Ablauf.

Schritt A

Datei bearbeiten — Texte, Bilder oder Kontaktdaten anpassen

→
Schritt B

Änderung speichern — mit kurzer Beschreibung, was sich geändert hat

→
Schritt C

Zu GitHub hochladen — die Live-Seite aktualisiert sich automatisch

Rund eine Minute nach dem Hochladen ist die Änderung live sichtbar.

Kurzes Glossar

Die wichtigsten Begriffe, einfach erklärt.

Repository
Ein Online-Ordner für Projektdateien, inklusive aller früheren Versionen.
Git
Das Werkzeug, das Änderungen an Dateien nachvollziehbar speichert.
Commit
Ein gespeicherter Änderungsstand mit kurzer Beschreibung, was sich geändert hat.
Push
Änderungen vom eigenen Rechner zu GitHub hochladen.
GitHub Pages
Kostenloser Dienst, der ein Repository automatisch als Website veröffentlicht.
Hosting
Der Vorgang, eine Website dauerhaft und öffentlich im Internet erreichbar zu machen.
